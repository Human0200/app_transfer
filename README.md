# App Transfer

Небольшая нативная утилита для macOS, которая переносит приложение или папку
на другой диск, проверяет копию и оставляет символическую ссылку на исходном
пути. Благодаря этому приложение продолжает находить свои данные.

## Возможности

- выбор диска или папки-источника;
- выбор приложения `.app` или папки для переноса;
- выбор внешнего диска или папки назначения;
- проверка размера скопированных данных;
- создание символической ссылки на исходном пути;
- понятный статус операции и индикация прогресса;
- встроенная иконка приложения с буквой `R`.

## Требования

- macOS 13 Ventura или новее;
- Xcode Command Line Tools со Swift 5.9 или новее.

## Запуск из исходников

```sh
swift run
```

## Сборка `.app`

```sh
./Scripts/build-app.sh
```

Результат появится в `dist/App Transfer.app`. Скрипт собирает release-бинарник,
создаёт иконку `AppIcon.icns` и добавляет её в bundle приложения.

## Использование

1. Нажмите `Источник` и выберите диск или папку, где находится объект.
2. Выберите приложение или папку в списке.
3. Выберите диск назначения.
4. Нажмите `Перенести выбранное` и подтвердите операцию.

Утилита сначала копирует объект, затем проверяет копию и только после этого
заменяет исходный путь символической ссылкой.

## Ограничения и безопасность

Перенос `.app` не гарантирует перенос всех данных приложения: часть программ
хранит настройки и кэш в разных местах. Для таких случаев можно выбрать папку
данных вручную. Системные папки, сам App Transfer и уже созданные символические
ссылки утилита не переносит.

Перед переносом убедитесь, что диск назначения подключён и на нём достаточно
свободного места. Не отключайте диск во время операции. Для возврата объекта на
исходный диск удалите символическую ссылку и верните объект из папки
`App Transfer` вручную.

## GitHub Release

Релиз можно собрать и опубликовать через GitHub CLI:

```sh
./Scripts/build-app.sh
ditto -c -k --sequesterRsrc --keepParent \
  "dist/App Transfer.app" "dist/App-Transfer-macOS.zip"
gh release create v0.1.0 "dist/App-Transfer-macOS.zip" \
  --title "App Transfer v0.1.0" \
  --generate-notes
```
